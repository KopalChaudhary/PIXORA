PIXORA — Beyond the Edit is a modern, user-friendly web-based image editor designed to make photo editing simple, creative, and accessible. Users can upload an image and edit it directly in their browser without requiring additional software.

PIXORA provides editing tools such as brightness, contrast, saturation, grayscale, temperature, sharpening, cropping, rotation, and flipping. It also includes features such as undo/redo, reset, zoom, and image saving.

The project is built using HTML, CSS, JavaScript, and the Canvas API, with a clean, soft, and responsive user interface designed for an easy editing experience.
